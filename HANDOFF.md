```
deliberately lighter than a case study.

  { slug, title, caption (one line, max 90 chars),
    domain: 'detection'|'tracking'|'ocr'|'depth'|'anomaly'|'pose'|'segmentation',
    poster, video?, cleared: boolean }

Seed it from assets/drive/UP-Videos/. I will write the captions — generate

you found so I can fill them in. DO NOT write captions yourself and DO NOT
guess what a clip shows from its folder name.

`cleared: false` items DO NOT RENDER. Several of these are client work
(Jetson deployments, railway lidar, pig counting are not hobby projects)
and need the same clearance rule that governs magicqc and
industrial-pose-suite in CLAUDE.md §7.

Performance is the hard part — 33 videos will destroy the motion budget in
CLAUDE.md §4:
  - poster-first, always. Never autoplay on load.
  - IntersectionObserver mounts a <video> only when in view; unmount on exit.
  - play on hover only, and only when matchMedia('(hover: hover)') and
    navigator.connection.saveData is falsy.
  - at most 3 video elements alive at once. Evict by distance from viewport.
  - prefers-reduced-motion: posters only, no video elements at all.

Filter by domain is client-side over a server-rendered list — the grid must
be complete and readable with JS disabled.

Report the JS delta for /lab and confirm the home route is unchanged.
```

## 6. Guardrails — restate these in every session

These are the rules an agent under time pressure quietly drops.

1. **Never invent a metric, client, date or outcome.** Every number traces to the
   CV. A slot with no number renders empty.
2. **Never write a testimonial.** The five in the file are real. Nothing gets added
   that a person did not write.
3. **`DRAFT:` fields are Hamza's.** 14 of them across 9 projects. Surface them in a
   checklist; do not guess. A reviewer reads `limitations` first because it is the
   only part of a portfolio that cannot be faked.
4. **No borrowed copy.** Grep for `motion instead of chrome`, `reads your presence`,
   `a living interface`, `northwind`, `clinic rota`, `silent.axiss` before every
   commit. All of it goes.
5. **Confidential projects stay at CV level.** `magicqc`, `industrial-pose-suite`,
   `skyresq`. No client footage, no logos, no detail beyond what the CV states.
6. **Screenshot it before saying it works.** A passing build is not evidence that
   anything renders correctly.
